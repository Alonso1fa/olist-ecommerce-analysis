# Power BI File

Place the final Power BI project here using a descriptive filename such
as:

`olist_ecommerce_dashboard.pbix`

The `.pbix` file is not generated by this repository package because the
final working file is stored locally in Power BI Desktop.

The dashboard should match the screenshot in `../images/dashboard.png`.

Main measures and modeling decisions are documented in the root
`README.md`.
