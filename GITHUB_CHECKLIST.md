# GitHub Upload Checklist

1.  Copy your final `.pbix` file into the `powerbi/` folder.
2.  Confirm `images/dashboard.png` is the final dashboard screenshot.
3.  Optional: add `images/data_model.png` from Power BI Model view.
4.  Do **not** upload the raw Olist CSV files.
5.  Create a new public GitHub repository named
    `olist-ecommerce-analysis`.
6.  Upload the complete contents of this folder, preserving the folder
    structure.
7.  Verify that the image renders near the top of `README.md`.
8.  Open each `.sql` file on GitHub and confirm syntax highlighting is
    working.
9.  Copy the public repository URL.
10. Open `docs/linkedin_post.md`, replace `[PEGAR LINK DE GITHUB]`, and
    publish it with the dashboard screenshot.
